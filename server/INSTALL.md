# Установка сервера WesiOS — пошагово

Для сервера, купленного на Aeza. С нуля до работающей синхронизации —
**одна команда** и примерно десять минут, из которых пять уходит на ожидание.

Всё, что нужно уметь: скопировать команду и вставить её в чёрное окно.

---

## Шаг 0. Что взять из панели Aeza

Зайдите на **my.aeza.net** → ваш сервер. Нужны три вещи:

| Что | Где | Пример |
|---|---|---|
| IP-адрес | на карточке сервера | `185.221.199.19` |
| Пароль root | там же, кнопка «Показать» | длинная строка |
| Кнопка VNC | на карточке | понадобится, только если сломается SSH |

> Пароль root Aeza присылает и на почту при создании сервера. Если вы его
> меняли — нужен новый, а не тот, что из письма.

**Про VNC.** Это запасной вход прямо в консоль машины, минуя сеть. Если
вы случайно закроете себе SSH файрволом — не паникуйте, заходите через VNC
и чините. Потерять сервер по этой причине нельзя.

## Шаг 1. Зайти на сервер

**Windows.** Откройте **PowerShell** (кнопка «Пуск» → наберите `powershell`).
SSH там уже встроен, ставить ничего не надо.

```powershell
ssh root@ВАШ_IP
```

Первый раз спросит `Are you sure you want to continue connecting?` — наберите
`yes` и Enter. Потом попросит пароль.

> **Пароль не отображается при вводе** — ни точками, ни звёздочками. Это не
> зависший терминал, так задумано. Вставьте пароль правой кнопкой мыши и
> нажмите Enter.

Получилось, если строка стала вида `root@aeza-...:~#`.

**Android.** Приложение Termius или JuiceSSH — то же самое, но с полями
вместо команды.

## Шаг 2. Одна команда

Скопируйте целиком и вставьте:

```bash
curl -fsSL https://raw.githubusercontent.com/wesiwer/WesiOS/main/server/quick-install.sh -o /root/wesios.sh && bash /root/wesios.sh
```

Пять минут — и всё. Скрипт сам:

- ставит PocketBase службой с автозапуском;
- заводит отдельного пользователя (не root — если службу однажды взломают,
  взломщик получит один каталог, а не сервер целиком);
- настраивает файрвол, **сначала разрешив SSH** — обратный порядок был бы
  верным способом отрезать себя от собственного сервера;
- создаёт коллекцию, индекс и правила доступа;
- заводит учётную запись для входа из приложения;
- ставит агента, который показывает нагрузку сервера;
- **придумывает пароли сам** и печатает их в конце.

Пароли придумывать не нужно: набранный в спешке руками обычно слабее
случайного и всё равно теряется. Скрипт делает по двадцать символов без
похожих `l/I/1` и `O/0` — их придётся один раз прочитать глазами.

В конце он напечатает готовые строки для приложения и продублирует их в
`/root/wesios-credentials.txt`.

> **Перепишите пароли себе сразу.** Почтовые порты у хостера закрыты, письмо
> со сбросом отправить не с чего — восстановить их нечем.

Повторный запуск ничего не ломает: пароли берутся прежние, существующее не
пересоздаётся.

## Шаг 3. Подключить приложение

В WesiOS: **Настройки → Данные → Синхронизация** — введите то, что напечатал
скрипт:

```
адрес:  ВАШ_IP:8090
логин:  wesi@wesios.local
пароль: тот, что напечатал скрипт
```

**Войти** → **Синхронизировать сейчас**.

Приложение показывает, на какой адрес реально уйдёт запрос: набранное
`185.221.199.19:8090` превратится в `http://185.221.199.19:8090`. Так и
должно быть — у голого IP сертификата нет.

Дальше включите **«Автоматически при запуске»**, и обмен будет идти сам.

---

## Шаг 4. Нагрузка сервера в приложении

Агент уже стоит — осталось добавить узел в приложении:

**Ещё → Системный администратор → плюс**

```
тип:          Сервер
адрес:        ВАШ_IP
порт:         8090
адрес агента: http://ВАШ_IP:8090/wesios-status.json
```

## Если хочется по шагам

Быстрая команда — это просто обёртка над тремя скриптами. Кому нужно
понимать, что происходит, или что-то поменять, — запускайте их по
отдельности:

```bash
# 1. только PocketBase
curl -fsSL https://raw.githubusercontent.com/wesiwer/WesiOS/main/server/install-sync.sh -o /root/a.sh && bash /root/a.sh

# 2. коллекция, правила и учётная запись — со своими паролями
curl -fsSL https://raw.githubusercontent.com/wesiwer/WesiOS/main/server/setup-collections.sh -o /root/b.sh
bash /root/b.sh --admin ПОЧТА --admin-pass ПАРОЛЬ --user ПОЧТА --user-pass ПАРОЛЬ

# 3. агент нагрузки
curl -fsSL https://raw.githubusercontent.com/wesiwer/WesiOS/main/server/wesios-agent.sh -o /root/c.sh && bash /root/c.sh --install
```

## Особенности Aeza, о которых стоит знать заранее

**Почта не работает.** Порты 25, 465 и 587 закрыты у большинства хостеров по
умолчанию, чтобы с серверов не рассылали спам. Для нас это не мешает —
учётные записи заводите вы сами, — но означает, что **сброс пароля по почте
невозможен**. Отсюда настойчивая просьба записать пароли.

Если почта понадобится: у Aeza её открывают по заявке в поддержку, либо
подключается сторонний SMTP (Яндекс 360) в панели PocketBase.

**Файрвол.** Скрипт настраивает `ufw` на самом сервере. В панели Aeza на
некоторых тарифах есть ещё и свой сетевой фильтр — если после установки
`ВАШ_IP:8090` не открывается в браузере, проверьте его.

**Резервные копии.** У Aeza они платные и не включены по умолчанию. Свои
можно поднять одной командой — в `server/README.md`, раздел «Резервные
копии». Копия базы — это один файл.

**Один процессор, два гигабайта.** PocketBase съедает 50–80 МБ. Запас
большой, но не ставьте на эту же машину ничего тяжёлого: VPN и модели для
Wesi AI просятся на отдельную.

## Если что-то пошло не так

| Что видите | Что делать |
|---|---|
| `Permission denied` при входе | Пароль не тот. Возьмите из панели Aeza заново |
| `Connection refused` при входе | Сервер выключен или ещё создаётся — подождите пару минут |
| Скрипт остановился с ошибкой | Он печатает ответ сервера целиком — пришлите мне этот вывод |
| Панель не открывается в браузере | Проверьте фильтр в панели Aeza (см. выше) |
| В приложении «Нет связи с сервером» | Проверьте: `systemctl status pocketbase` на сервере |
| Совсем закрыли себе SSH | Заходите через VNC из панели Aeza, потом `ufw allow OpenSSH` |

Полезные команды:

```bash
systemctl status pocketbase      # работает ли служба
journalctl -u pocketbase -f      # что она пишет прямо сейчас
systemctl restart pocketbase     # перезапустить
ufw status                       # какие порты открыты
```

## Что прислать мне после установки

1. **Последний экран скрипта** — тот, что в рамке. Пароли можно закрасить,
   мне нужны адрес и версия PocketBase.
2. **Версию PocketBase** — она есть на том же экране. Важна: в версии 0.23
   переименовали часть API, и я не могу отсюда проверить, какая встанет.
   В скриптах предусмотрены оба варианта, но хочу знать наверняка.
3. **Любую ошибку целиком**, если появится.

После этого берусь за реальные учётные записи сотрудников — карточки, права,
хеши паролей и фотографии уже готовы ездить, ждут только сервера.
