## Правила дальнейших изменений

- После каждого значимого изменения обновлять `TZ.md`, `docs/WESI_AI_MASTER_SPEC.md` (если затронута архитектура Wesi AI) и при необходимости `STATUS.md`.
- Не ломать обратную совместимость Hive/JSON без явной миграции.
- Не коммитить secrets, keystore, токены и пароли.
- Релизные билды запускать только по явному запросу пользователя.
- Policy/Sandbox слой Wesi AI нельзя обходить ради удобства.
- Тяжёлые runtime dependencies должны устанавливаться модульно через Runtime Packs с предварительным Environment Scan и переиспользованием совместимых системных установок.

> Примечание: подробные исторические требования до 2026-08-15 доступны в Git history `TZ.md`; отдельные специализированные ТЗ остаются в `TZ_ORG_HIERARCHY_V1*.md` и других документах репозитория.
