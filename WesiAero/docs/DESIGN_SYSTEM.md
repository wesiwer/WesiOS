# Дизайн-система Wesi Aero

## Визуальная идея

Wesi Aero — родственник WesiOS, а не копия типового VPN-приложения. От референсов
сохранена композиция «статус → power control → сервер → телеметрия», но убраны
рекламный баннер, кислотный сине-бирюзовый градиент и декоративный шум.

Главное ощущение: спокойный защищённый инструмент, который живёт внутри той же
«операционной системы бизнеса», что WesiOS.

## Цветовые токены

| Роль | Dark | Light |
| --- | --- | --- |
| Background | `#09090B` | `#F8F9FC` |
| Surface | `#18181B` | `#FFFFFF` |
| Raised | `#27272A` | `#EEF1F6` |
| Primary text | `#FFFFFF` | `#172033` |
| Secondary text | `#D4D4D8` | `#465166` |
| Muted text | `#A1A1AA` | `#667085` |
| Primary accent | `#F97316` | `#2563EB` |
| Protected | `#38BDF8` | `#607F9E` |
| Error | `#F87171` | `#B42318` |

Оранжевый в тёмной теме означает действие и выбор, а в основной светлой теме
это делает фирменный синий. Защищённое состояние отмечается чистым голубым в
тёмной теме и спокойным серо-голубым в светлой. Цвет не является единственным
носителем смысла: каждый статус имеет текст и иконку.

## Геометрия

- spacing: `4 / 8 / 12 / 16 / 24 / 32 / 48`;
- radii: `10 / 14 / 20 / 28`;
- минимальная интерактивная область: 48×48;
- мобильные поля: 16 px;
- desktop content max-width: 1240 px;
- desktop breakpoint: 960 px.

## Типографика

- 36: display/hero;
- 28: основной заголовок;
- 22: заголовок раздела;
- 18/16: карточки и controls;
- 14: основной текст;
- 13: labels;
- 11 допускается только для коротких uppercase badges с повышенным контрастом.

## Компоненты

### Aero Orb

- disconnected: оранжевая дуга, слабый glow;
- connecting: ускоренное вращение, progress indicator;
- connected: голубой или серо-голубой breathing glow и спокойное вращение частиц;
- disconnecting: янтарный цвет;
- error: красный цвет и неизменяемый текст причины.

Нажатие даёт scale `1 → 0.965`, hover на Windows — `1 → 1.025`. При Reduced
Motion циклы фиксируются, но смена состояния остаётся видимой.

### Glass Card

Backdrop blur 12–18, тонкая граница, слабая тень. Карточка используется для
самостоятельного действия или группы данных, но не оборачивает каждый текстовый
элемент — это защищает интерфейс от «card soup».

### Навигация

- Android/узкое окно: 4 пункта в BottomNavigationBar;
- Windows ≥960 px: NavigationRail, extended при ≥1120 px;
- shell остаётся на месте при переходе между модулями.

## Motion

| Токен | Время | Применение |
| --- | ---: | --- |
| Quick | 160 ms | press, hover, toggle |
| Normal | 280 ms | status, chip, card state |
| Expressive | 420 ms | экран, тема, крупный layout change |
| Ambient | 5–18 s | orb и фоновые циклы |

Анимации используют `easeOutCubic`; важные переходы не зависят от сложных
spring-эффектов. UI-телеметрия обновляется раз в секунду и не должна вызывать
перерисовку всего приложения.
