# Wesi Aero Admin

Flutter-клиент управления Wesi Aero для Android и Windows. В приложении есть:

- серверы: создание, изменение, удаление, протоколы, нагрузка, ёмкость и JSON транспорта;
- тарифы: цены для общего/индивидуального IP, пяти сроков и 1–5 устройств;
- ключи: бесплатная генерация, копирование, отзыв и счётчик устройств;
- оплаты: состояние заказов, тестовое подтверждение, сверка и включение провайдеров;
- безопасное подключение к Admin API по HTTPS с токеном в защищённом хранилище.

Без URL и admin token приложение запускается в демонстрационном режиме. Для общей
синхронизации Admin и установленных клиентов укажите URL развёрнутого control plane.
Платёжные секреты вводятся только как переменные окружения сервера и не хранятся в
Admin-приложении.
